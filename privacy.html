过日子使用帮助与联系隐私政策

隐私政策

更新日期与生效日期：2026年11月11日
适用应用：过日子-倒数日与纪念日（iOS 1.0）

本应用由 Shenzhen Huoli Zhihui Technology Co., Ltd.（以下称“我们”）提供。本政策说明应用如何处理你在设备上记录的内容，以及你使用备份、分享和系统权限时的数据流向。

本版本无需账号，不接入业务服务器。日子记录在本地保存和计算，我们不会通过应用收集或主动上传你的日子、备注、备份文件或使用行为。导出、导入、分享和设备系统备份由你及系统设置决定。

1. 在设备上保存的内容

为了记录和显示日子，应用会在设备内保存你填写的名称、日期、历法、分类、备注、配色、图标、重复与计数方式、首页主卡选择及提醒设置。每条记录还包含用于本地识别和关联的编号，该编号不用于广告或跨应用追踪。

  • 日子记录：用于倒数与正数、公历及农历日期计算、搜索、月历和详情显示。
  • 小组件快照：应用会将本地记录的快照写入仅供本应用和配套小组件使用的设备共享容器，以显示与更新小组件。小组件可能显示名称、日期和备注，请留意桌面上可被他人看见的内容。
  • 导入前副本：成功导入备份前，应用保留最近一次导入前的记录和相关状态，供你撤回或导出。下一次成功导入会替换旧副本；撤回导入会清理对应副本。
  • 本地偏好：例如最近一次保存备份的时间，用于帮助你了解备份情况。
  • 异常文件副本：读取原有记录失败时，应用可能在设备内保留原始文件，避免直接覆盖。

上述内容由应用在设备上处理，不会自动发送给我们。应用没有账号、跨设备云同步或开发者可读取的在线记录库。

2. 系统权限和本地提醒

通知：你主动开启提醒时，应用会在需要时请求系统通知权限，并将对应名称、提醒内容和时间交给设备上的通知服务安排。应用不使用业务服务器推送。提醒内容可能出现在锁屏或通知中心，你可以在 iOS 通知设置中调整预览、横幅和声音，也可以在应用中关闭某条日子的提醒。

保存分享图片：你主动生成分享卡片后，图片会交给 iOS 系统分享面板。若你选择保存到照片，系统可能请求向相册添加图片的权限；本应用不读取你的照片库。拒绝相册权限不影响记录日子。

文件：备份导入和导出通过系统文件选择器进行。应用只处理你选择导入的备份文件，或将备份写到你选择的位置。你可以在 iOS 设置中更改可用权限；关闭通知权限后，本地记录功能仍可使用。

3. 备份、导入和分享

你选择“保存备份”时，应用会生成包含记录内容的 JSON 文件；你选择分享时，分享图片可能包含日子名称、日期、计数和备注。保存位置、接收对象及使用的应用由你在系统界面中选择。我们不会自动接收这些文件或图片。

若你选择 iCloud Drive、其他云盘、通信应用或其他服务，相关服务会按其自身规则处理你交给它的内容。iOS 的整机备份、设备迁移或恢复，也可能依据你的系统设置包含本应用数据。这些系统行为与应用提供账号云同步不同。

备份文件包含可直接读取的记录内容，分享图片也可能包含私人信息。请自行选择合适的保存位置与接收方。分享图片不能代替可恢复记录的 JSON 备份。

4. 收集、追踪与第三方组件

本版本不集成广告、第三方统计或用户画像 SDK，不读取广告标识符，不通过应用收集设备标识、位置、联系人、照片库内容或使用行为。日子管理不需要定位、相机、麦克风或联系人权限。

应用使用 iOS 提供的通知、文件、分享和小组件能力。Apple 及你主动选择的文件或分享服务可能根据其各自的服务条款、隐私说明和你的系统设置处理数据。本政策描述的是本应用的处理方式。

5. 保留、修改和删除

你可以在应用中编辑或删除日子。删除操作会更新当前记录、小组件快照及待安排提醒，但最近一次导入前副本或异常保留文件中仍可能存在旧内容。已送达的通知可以在通知中心自行清除。

如需清理设备内本应用的数据，可使用 iOS 的“删除 App”功能。请注意，“卸载 App”保留文稿与数据的系统选项与“删除 App”不同；导出到文件、照片或其他服务中的副本，以及系统备份中的内容，需要你在对应位置另行管理。

我们无法从设备外读取、修改或恢复你的本地记录。删除应用、设备丢失或系统恢复可能影响本地数据，重要记录请先保存备份。若你通过下方联系渠道主动提供问题说明、联系方式或附件，我们会使用这些内容处理你的请求；不需要发送完整日子记录时，请避免附上备份或私人内容。

6. 儿童使用

本应用不以儿童为特定服务对象，也不要求提供年龄、身份或账号信息。儿童使用时，建议由监护人协助管理设备权限、备份和分享对象。

7. 支持网站

本隐私政策和支持网页由 GitHub Pages 静态托管，不是日子数据的业务服务器。访问网页或主动使用 GitHub Issues 时，GitHub 可能依据其隐私声明处理网络连接和账号等信息。公开反馈可能被他人查看，请只提供排查所需且已去除私人内容的信息。应用不会自动打开支持网站或将本地记录交给网站。

8. 政策更新与联系

应用功能或数据处理方式发生变化时，我们会相应更新本政策，并标明更新日期。
