使用帮助与联系

过日子-倒数日与纪念日，帮你记住生日、纪念日和接下来的期待。无需账号，记录保存在设备本地。

适用于 iOS 1.0 · 更新于2026年11月11日

记录与计数

怎样记一个日子？

从首页添加日子，填写名称并选择日期即可保存。你还可以设置备注、分类、颜色、图标、是否每年重复、是否包含首日及提醒。打开某个日子的详情，可以继续编辑或删除。

倒数和正数怎样计算？

应用按设备当前时区的日历日期计算。明天是1天后，今天显示0天；过去的日期显示已经过的天数。对不重复的日子，可选择是否包含第一天。每年重复的日子到当天时仍显示0天。

农历生日怎样设置？

在日期选择中切换到农历，按农历年、月、日选择；应用会显示对应公历日期。开启“每年重复”后，按所选历法寻找下一次日期。普通月生日每年使用普通月；闰月日子在有同名闰月时使用闰月，否则使用普通月。原日期为三十而当年该月没有三十时，使用该月最后一天。公历2月29日每年重复时，平年使用2月28日。

如何查找记录或更换首页主卡？

可以用首页分类、搜索和月历查看日子。在记录相关操作中设置首页主卡；未指定时，首页和小组件按应用的日期顺序选择日子。

提醒与小组件

怎样开启提醒？

编辑日子时开启提醒，可选择当天或提前1、3、7天；在首页菜单的“提醒管理”中可以集中查看和开关。第一次需要提醒时，按系统提示允许通知。若曾拒绝，请到 iOS 设置中找到本应用，开启通知后再回到应用核对安排状态。

为什么没有看到提醒？

先在“提醒管理”查看是否有下一次提醒时间，再检查系统通知权限、横幅、声音、锁屏预览和专注模式。已经过去的提醒时间不能补发；安排过多时，应用优先安排近期日子。提醒由 iOS 调度，年度重复提醒会在再次打开应用时继续核对和安排。

怎样添加桌面小组件？

先打开应用并保存记录，再在 iPhone 桌面长按空白处进入编辑，选择添加小组件，搜索“过日子”，选择小号或中号组件。应用菜单的“桌面小组件”中也有尺寸预览和添加说明。组件跟随首页主卡，具体刷新时机由 iOS 决定；内容未更新时，可先打开应用核对记录。

小组件和锁屏通知可能让旁人看到日子内容，私人备注请按自己的使用场景填写。

备份与恢复

怎样保存备份？

打开首页菜单中的“备份与恢复”，选择保存备份，在系统文件选择器中确定保存位置。备份是 JSON 文件，可保留到你选择的本机文件夹、电脑或文件服务。日历分享图片只用于展示，不能用于恢复记录。

怎样导入或更换手机？

先在原设备导出 JSON 备份并妥善保存，再在新设备安装应用，从“备份与恢复”选择该文件。确认导入前可以核对新增、内容不同和已存在的数量；默认只加入新日子，同一条记录的不同内容需主动选择是否使用备份内容。应用没有账号登录或自动云同步。

导入后怎样撤回？

应用会保留最近一次导入前的副本。若导入后还没有改动记录，可以在“备份与恢复”中撤回；若已新增或修改，可先导出导入前副本，再按需导入。下一次成功导入会替换旧副本，重要数据请另外保存独立备份。

为什么备份无法导入？

请选择本应用导出的 JSON 备份，文件大小不要超过10 MB。文件损坏、重复编号、缺少名称或无法识别的提醒设置会导致导入被拒绝。若文件正在云盘中，先确认它已能在系统“文件”应用中打开。不要为了排查而删除现有应用或原始备份。

删除应用前需要做什么？

先导出并检查备份是否已保存到你能找到的位置。应用记录在本地，我们无法远程找回。已导出的文件、分享图片和系统备份不会因删除某条日子而自动删除，需要到对应位置管理。
